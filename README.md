# 知の打鍵

歴史・科学・文化・ニュースの解説を、ローマ字で一文ずつ打ちながら読むタイピング練習アプリです。各テーマの出典から元の資料を読めます。

## 遊び方

- ジャンルを選び、表示されたローマ字を半角英数で入力します。スマートフォンでは文章欄をタップして英字キーボードを開きます。
- 一文打ち終えるたびに次の文が表示されます。四文を読み終えると、テーマ全体を振り返れます。
- 「次のテーマ」で新しい題材に進めます。キーボードでは読了後に Enter でも進めます。Esc で現在のテーマを最初から練習できます。
- 入力速度・正確率・経過時間を表示します。読了したテーマの練習記録は、このブラウザに保存されます。

ニュースの題材は、日付と出典を添えた解説です。各ジャンルでは収録テーマを一巡するまで同じ題材を出さず、一巡後は順番を変えて練習を続けられます。

## ローカルで開く

`docs/index.html` をブラウザで開いてください。インストールやビルドは不要です。

GitHub Pages の公開元には `main` ブランチの `/docs` を指定します。

## テーマを追加する

`docs/stories.js` と `docs/facts-extra.js` に教材があります。題名、ジャンル、出典、四文の本文とひらがなの読みを追加します。ニュースの教材には ISO 形式の発生日も設定します。
