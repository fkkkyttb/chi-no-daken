# 知の打鍵

歴史・科学・文化・ニュースと、日本語の語彙を学べるローマ字タイピング練習です。解説テーマには出典があり、ニュースは出来事の日付も表示します。

## 遊び方

- ジャンルを選び、表示されたローマ字を半角英数で入力します。スマートフォンでは文章欄をタップして英字キーボードを開きます。
- 一回の練習に複数の題材が入ります。初回は毎分200打、次回からは最近の練習速度をもとに約5分ぶんの文章を選びます。最後の文を打ち終えると完了です。
- 歴史などのジャンルにも、その分野で使われることばが登場します。「語彙」を選ぶと語彙だけを練習できます。
- 練習中は「一時停止」または Esc で休憩できます。結果画面で文章・出典・語彙を読み返せます。練習結果と語彙帳は、このブラウザに保存されます。

## ローカルで開く

`docs/index.html` をブラウザで開いてください。インストールやビルドは不要です。GitHub Pages の公開元は `main` ブランチの `/docs` です。

## 教材を追加する

- 解説は `docs/facts-expanded.js` に追加します。題名、ジャンル、出典、本文と読みを設定します。ニュースには出来事の日付も ISO 形式で添えます。
- 語彙は `docs/vocabulary.js` に追加します。単語、読み、意味、出題する分野、練習文と読みを設定します。
- 練習文の読みはひらがなで記し、句読点や長音符を本文と揃えます。ブラウザで入力して読みとローマ字の案内を確認してから公開します。
